# VTS Prototype

## 项目信息
- 项目名称：VTS Prototype
- 技术栈：Vue3 + Vite + TypeScript + GIS（Leaflet/WebGL）

## 常用命令
- `npm install`
- `npm run dev`
- `npm run build`

## 编码规范
- 使用 TypeScript
- 采用组件化开发
- 命名保持统一，使用 `camelCase`
- 每个文件禁止超过500行，如果新建文件必须要在根目录下“PROJECT_STRUCTURE_SKILL.md”文件进行更新。
- 每次有模块、路由级别的需求改动都需要更新prd文件（在根目录下）。

## 仓库说明
- skills 位于 `.agents/skills`
- specs 位于 `specs/`
- docs 位于 `docs/pages/`
