# Backlog

## 任务1：在Home页侧边栏新增船舶详情模块

### 需求描述
- 在Home页侧边栏新增一个船舶详情模块，展示当前选中船舶的详细信息，包括但不限于船名、类型、位置、速度等基本信息，以及航线、历史轨迹等相关数据。
- 和VHF、意图识别、风险预警、锚地统计等模块保持一致的设计风格，确保整体界面的一致性和美观性。


### 交互设计
- 当用户在地图上点击某个船舶时，侧边栏的船舶详情模块会自动更新，显示该船舶的详细信息。
- 用户可以在船舶详情模块中查看该船舶的历史轨迹，点击轨迹点可以在地图上高亮显示对应位置。
- 用户可以通过搜索功能快速定位到特定船舶，并在侧边栏查看其详情。

### 验收标准
- 侧边栏成功新增船舶详情模块，并能正确显示选中船舶的详细信息。
- 用户点击地图上的船舶时，侧边栏信息能够正确更新。
- 用户能够通过搜索功能快速定位到特定船舶，并查看其详情。
