# 01. 产品总览

## 1. 产品定位

`VTS Prototype` 是一个面向船舶交通管理场景的智能辅助原型系统，核心目标是把地图、船舶、VHF、意图、预警、锚地和后台管理能力汇聚到一个可视化工作台中。

## 2. 目标用户

- VTS 值班员
- 运行调度人员
- 风险与规则管理人员
- 演示汇报与培训人员

## 3. 产品目标

### 3.1 监控值班目标

- 通过地图统一承载动态态势
- 快速切换船舶、VHF、意图、预警、锚地等业务视图
- 从预警事件直接联动到轨迹回放

### 3.2 后台管理目标

- 提供区域设置、船舶动态、业务统计、预警管理、场景演示等运营与配置能力
- 支持预警规则配置、风险列表查看、风险看板分析和重点区域监控

## 4. 当前系统边界

- 当前以 Mock 数据驱动为主
- 当前不包含登录鉴权、真实接口、后端存储
- 当前未采用 URL 级页面路由
- 当前的后台管理是主应用上的整屏覆盖层

## 5. 一级信息架构

### 5.1 主工作台

- 顶部栏
- 侧栏
- 地图区
- 底部栏
- 全屏回放层
- 后台管理层

### 5.2 主侧栏业务域

- 船舶
- VHF
- 意图
- 预警
- 锚地

### 5.3 后台业务域

- 区域设置
- 船舶动态
- 业务统计
- 预警管理
- 场景演示
- 若干占位中的基础管理菜单

## 6. 当前最完整的业务模块

目前实现最完整、最适合作为后续扩展模板的模块是：

- 预警管理

其内部已经形成：

- 规则策略
- 风险列表
- 风险看板
- 重点区域
- 动态回放联动
