# 03. 主工作台 PRD

## 1. 页面目标

主工作台是系统的核心使用界面，负责在一个屏幕中同时承载：

- 地图态势
- 船舶详情
- VHF 通信
- 意图识别
- 预警信息
- 锚地态势

## 2. 页面组成

来源：
[src/features/app/AppView.tsx](/Applications/VTS/VTS-Prototype/src/features/app/AppView.tsx)

### 2.1 顶部栏

- 系统名称展示
- 打开后台管理
- 用户菜单

### 2.2 侧栏

- 业务 Tab 切换
- 船舶搜索
- 各业务面板承载区

### 2.3 地图区

- Leaflet 地图承载
- 船舶 Marker
- 风险/事件叠加标识
- 船舶轨迹和回放联动

### 2.4 消息推送列表

- 位于地图右侧，以悬浮列表形式展示。
- 模拟实时推送船舶意图、预警信息、天气提醒。
- 支持自动淡出和手动关闭。

### 2.5 底部栏

- 鼠标经纬度
- 比例尺/状态信息
- 控制面板展开状态

## 3. 主侧栏业务需求

### 3.1 船舶

- 显示当前选中船舶详情
- 显示轨迹点与动态事件
- 支持轨迹点与地图联动

### 3.2 VHF

- 支持列表/对话流视图
- 支持台站选择
- 支持 SAAB 联动开关
- 显示活动会话与等待会话

### 3.3 意图

- 支持按类型筛选
- 支持展开单条意图
- 展示意图摘要、建议和风险线索

### 3.4 预警

- 展示预警事件列表
- 支持展开查看预警内容
- 作为轻量监控入口，与后台“预警管理”形成分层

### 3.5 锚地

- 展示锚地列表
- 展示类型分布和时长分布
- 支持 chart / tags 视图切换

## 4. 核心状态路由

- `activeTab` 控制当前侧栏业务面板
- `selectedHomeShipId` 控制当前船舶
- `selectedIntent` 控制意图展开项
- `selectedAlert` 控制预警展开项
- `selectedAnchorage` 控制锚地选中项
- `dynamicPlaybackSession` 控制全屏回放
- `isAdminView` 控制后台管理覆盖层
