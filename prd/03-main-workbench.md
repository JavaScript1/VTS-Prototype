# 03. 主工作台 PRD

## 1. 页面目标

主工作台是系统的核心使用界面，负责在一个屏幕中同时承载：

- 地图态势
- 船舶详情
- VHF 通信
- 意图识别
- 预警信息
- 锚地态势

## 2. 页面组成

来源：
[src/features/app/AppView.tsx](/Applications/VTS/VTS-Prototype/src/features/app/AppView.tsx)

### 2.1 顶部栏

- 顶部中央提供状态驱动的模式路由，而不是 URL 路由
- 当前包含五个入口
- 其中 `标准模式` 和 `辅助模式` 作为一组模式切换强调展示
- 其余 `风险态势`、`执法辅助`、`应急处置` 作为专题路由切换
- 具体入口如下：
  - `标准模式`
  - `辅助模式`
  - `风险态势`
  - `执法辅助`
  - `应急处置`
- 右侧保留后台管理入口和用户菜单

### 2.2 侧栏

- 业务 Tab 切换
- 船舶搜索
- 各业务面板承载区

### 2.3 地图区

- Leaflet 地图承载
- 船舶 Marker
- 风险/事件叠加标识
- 船舶轨迹和回放联动

### 2.4 消息推送列表

- 标准模式下，消息推送以地图右侧悬浮列表方式展示。
- 辅助模式下，消息推送从浮层切换到右侧固定侧栏。
- 智能值班侧栏在消息列表下方展示数字人形象。
- 数字人根据当前可见消息自动切换为常态、紧急或事故形象，并联动高温 / 低温天气素材。
- 作为其他专题模式的复用消息组件，可嵌入专题右栏中。

### 2.5 底部栏

- 鼠标经纬度
- 比例尺/状态信息
- 控制面板展开状态

## 3. 主侧栏业务需求

### 3.1 船舶

- 显示当前选中船舶详情
- 显示轨迹点与动态事件
- 支持轨迹点与地图联动

### 3.2 VHF

- 支持列表/对话流视图
- 支持台站选择
- 支持 SAAB 联动开关
- 显示活动会话与等待会话

### 3.3 意图

- 支持按类型筛选
- 支持展开单条意图
- 展示意图摘要、建议和风险线索

### 3.4 预警

- 展示预警事件列表
- 支持展开查看预警内容
- 作为轻量监控入口，与后台“预警管理”形成分层

### 3.5 锚地

- 展示锚地列表
- 展示类型分布和时长分布
- 支持 chart / tags 视图切换

## 4. 核心状态路由

- `viewMode` 控制首页顶部模式切换
- `activeTab` 控制当前侧栏业务面板
- `selectedHomeShipId` 控制当前船舶
- `selectedIntent` 控制意图展开项
- `selectedAlert` 控制预警展开项
- `selectedAnchorage` 控制锚地选中项
- `dynamicPlaybackSession` 控制全屏回放
- `isAdminView` 控制后台管理覆盖层

## 5. 模式说明

### 5.1 标准模式

- 保持当前地图主页布局
- 左侧使用业务侧栏
- 右侧消息以浮层形式展示

### 5.2 辅助模式

- 左侧业务侧栏默认关闭，但仍可展开
- 右侧新增固定值班侧栏
- 消息推送集中放在右侧
- 右侧消息区底部展示会随消息和天气变化的数字人

### 5.3 风险态势

- 保留地图主画面
- 切换到风险态势专题工作台
- 包含辖区筛选、预警类型筛选、24 小时时间轴与热区回放
- 地图上展示热区假数据、热点排行与可播放的风险时序变化
- 承接原“执法辅助”模式中的预警回放能力，统一在风险态势内完成案例筛选、快照查看与动态回放
- 当前左侧主模块仅保留 `宏观态势` 与 `预警回放`
- `预警回放` 在右侧主内容区内直接嵌入动态回放，不再展示态势地图和案情摘要信息，并统一承载普通预警与碰撞预警案例
- `预警回放` 的搜索、分类和案件列表已迁移到风险态势左侧主栏，替代原“数据资源”区域
- 对于 `碰撞预警` 案例，嵌入回放会展示多船 Marker、船名气泡、随紧迫程度变化的镜头缩放，以及在预警触发时自动框选船群的闪烁红色预警多边形

### 5.4 执法辅助

- **核心目标**：实现对辖区违法嫌疑船舶的精准甄别、闭环证据链提取与高效拦截规划。
- **功能模块**：
  1. **甄别违法船舶**：基于预警事件、历史行为、通话记录与轨迹记录，识别包括禁航区航行、禁锚区锚泊、超速、异常停泊、谎报动态等在内的疑似违法行为。
  2. **形成执法线索**：为每一条执法对象形成完整的证据链，包含船舶信息、违法类型、时空要素、轨迹证据（航迹/速度/航向）、通话证据（VHF 语音记录）、预警证据及历史违章记录。
  3. **规划拦截/执法路线**：动态调度辖区海巡艇资源，展示在位海巡艇位置，计算航程距离与预计到达时间（ETA），评估拦截匹配度并提供执法方案建议（如现场拦截、VHF 通知等）。
- **页面布局**：
  - 左侧：疑似违法船舶甄别列表。
  - 中央：全域执法态势地图，支持热力分布与执法资源叠加。
  - 右侧：执法线索证据链详情面板。
  - 交互：支持“启动现场规划”浮层，进行资源调度与路径计算。
