# 04. 后台管理 PRD

## 1. 页面目标

后台管理用于承载配置、统计、演示与风险管理能力，是主工作台的运营与管理侧补充系统。

来源：
[src/features/admin/AdminPanel.tsx](/Applications/VTS/VTS-Prototype/src/features/admin/AdminPanel.tsx)

## 2. 页面结构

### 2.1 顶部区域

- 返回地图工作台

### 2.2 左侧菜单

- 展示后台一级菜单
- 点击切换主内容路由

### 2.3 主内容区

- 当前模块标题
- 面包屑式上下文文案
- 对应路由页面内容

## 3. 当前已实现菜单

### 3.1 区域设置

目标：

- 管理辖区分类与区域配置对象

当前能力：

- 分类 tab 切换
- 区域搜索
- 区域表格展示

### 3.2 船舶动态

目标：

- 管理和查看辖区内船舶动态对象

当前能力：

- 动态统计卡片
- 船舶动态列表
- 地图定位入口

### 3.3 业务统计

目标：

- 查看值班统计与意图统计概览

当前能力：

- 双 tab 切换
- 统计数量、高优先级数量、趋势值展示

### 3.4 预警管理

目标：

- 统一完成预警规则、风险处置、看板和重点区域监控

说明：

- 这是当前后台最完整的业务模块
- 详见 [05-warning-management.md](/Applications/VTS/VTS-Prototype/prd/05-warning-management.md)

### 3.5 场景演示

目标：

- 以演示用案例快速打开动态回放

当前能力：

- 风险事件卡片展示
- 一键打开动态回放

## 4. 当前占位菜单

- 个人信息
- 角色管理
- 权限管理
- 账号管理
- 字典管理
- 语音设置
- 显示设置

这些菜单当前保留信息架构位置，后续可按独立 route 继续补齐。

## 5. 后续建议

- 抽象后台菜单配置
- 增加权限模型
- 统一后台 CRUD 风格和表格筛选模板
